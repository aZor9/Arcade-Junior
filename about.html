À propos

Arcade Junior est une petite salle d’arcade de poche : des jeux de réflexion courts, pensés pour le téléphone, qu’on peut lancer, quitter et reprendre plus tard.

Les jeux

  • 2048 : fusionne les tuiles jusqu’à la valeur cible.
  • Mastermind : devine le code de couleurs.
  • Sudoku : de 4×4 à 9×9, chaque grille a une solution unique.
  • Nombre mystère : trouve le nombre avec des indications « plus grand / plus petit ».
  • Lumières : éteins toutes les ampoules.
  • Taquin : remets les tuiles dans l’ordre.
  • Mémoire : retrouve les paires.
  • Démineur : évite les mines.
  • Démêle : déplace les points pour que plus aucun trait n’en croise un autre.
  • Pipes : fais pivoter les tuyaux pour que l’eau arrive partout.
  • Takuzu : remplis la grille de 0 et de 1 sans triplé.
  • Hanoï : déplace la tour disque par disque.
  • Liaisons : relie les paires de même couleur sans croiser, en remplissant la grille.
  • Le compte est bon : atteins le nombre cible avec les quatre opérations.
  • Nonogram : dessine une image grâce aux indices de chaque ligne et colonne.
  • Puissance 4 : aligne quatre jetons avant l’ordinateur.

Comment ça marche

Chaque partie est générée au hasard sur ton appareil. Elle est enregistrée à chaque coup dans le stockage local de ton navigateur : tu peux lancer plusieurs parties, passer de l’une à l’autre, fermer l’onglet et revenir plus tard. Tu peux avoir jusqu’à 20 parties en cours. Une partie terminée est effacée, seules tes statistiques sont conservées.

Le site est entièrement statique : il n’y a ni serveur, ni compte, ni base de données. Une fois chargé, il fonctionne aussi sans connexion, et tu peux l’ajouter à ton écran d’accueil depuis le menu de ton navigateur.

Tes données

Tout reste sur ton appareil. Cela veut dire aussi que les parties ne passent pas d’un téléphone à l’autre : utilise « Exporter » puis « Importer » dans ton profil pour les déplacer. Plus de détails sur la page confidentialité.
